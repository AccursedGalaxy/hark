# Knowledge Vault — Agent Capture

This vault captures reusable insights, patterns, and decisions that are **not project-specific** and **not agent-lab learning curves** (those use `vaults/agent-lab`).

## Write Rules

- **§1 Logs**: Timestamped bullets in `logs/YYYY-MM-DD.md`. Always append; never edit existing bullets.
- **§2 Inbox notes**: Reusable concepts get a page in `00-inbox/` from `templates/capture-note.md`. These are drafts; the user promotes them to `10-notes/` when refined.
- **§3 Full notes**: `10-notes/` are user-authored understanding notes. The capture system writes **stubs only** here (CARDINAL RULE). Full content lives in `00-inbox/` first.

## Vault Sections

- `logs/` — daily timestamped capture; what was found/concluded.
- `00-inbox/` — candidate reusable concepts, awaiting promotion.
- `10-notes/` — user's refined understanding (user-authored only; stubs from capture).
- `templates/` — note templates for consistent structure.
